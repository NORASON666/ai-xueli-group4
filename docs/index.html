P4｜後端學生｜可複製

兩種測驗，方向一致嗎？

附件一是本校學力檢測報表，附件二是學習扶助測驗校級統計。請比較本校三科「未達基礎級」比率與學習扶助篩選測驗未通過率，說明兩者方向是否一致；不一致的話列出可能原因，並說明這兩項測驗的對象和時間有什麼不同。

五個陷阱

分析前後，都要停一下

  1. 數字可能讀錯：一定核對
  2. 跨年是不同屆學生
  3. 人數少，幾位學生就會影響比率
  4. 相關不等於因果：原因都是假設
  5. 跨年比較前先確認計分對象有沒有改變
